Inquirer: Different acharyas are saying maybe few common and few different things! Is it anekantavada - I.e., maybe describing only parts of it? If so, what’s the complete description of abhisheka?

Answer: Abhisheka details from Jaya Dhawala Book 1 by Acharya Veerasena
https://youtu.be/jQnzNMlusIg
1. ಣವಣ / Navana  = Abhishekas 
2. ಉಪ ಲೇಪನ / Upa Lepana
3. Pushpa Vrusti
4. ಸಮ್ಮಜಣ : Old dravya is cleaned/removed (with water).
5. ಚುಹಾವಣ : Similar to Upa lepana but only for feet. In upa lepana, chandana lepana is done for entire pratima. In Chuhavana, chandan lepana is done only for feet.
6. ⁠ಪುಲ್ಲಾರೋಹಣ: ಪುಷ್ಪಾರೋಹಣ - Aarohana/ putting flowers garland on pratima. (Not just feet, but entire pratima):
